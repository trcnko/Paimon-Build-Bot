# Маленькое приглашение

Отдельная автономная страница. Не использует код бота, не требует установки зависимостей, токенов или подключения к интернету.

## Как открыть

Открой `date-invitation/index.html` двойным кликом в Finder или перетащи его в окно браузера. Из терминала в корне репозитория на macOS:

```sh
open date-invitation/index.html
```

В VS Code можно выбрать файл и открыть через расширение Live Server, если оно уже установлено. Устанавливать его специально не нужно.

GitHub показывает исходный код HTML, а не саму страницу. Для просмотра скачай репозиторий (Code → Download ZIP), распакуй архив и открой `date-invitation/index.html` в браузере. Принимать PR или запускать бота не требуется.

## Что внутри

- Первый экран: «У тебя есть парень?» с кнопками «Да» и «Нет».
- «Да»: вежливое завершение.
- «Нет»: приглашение на свидание с возможностью согласиться или отказаться.
- Ответы не сохраняются и никуда не отправляются. После согласия страница предлагает ответить автору приглашения самостоятельно.
- После обновления страницы снова появляется первый вопрос.

Весь текст, оформление и логика находятся в `index.html`. Чтобы изменить приглашение, отредактируй текст соответствующего блока. Страница адаптируется под телефон, поддерживает навигацию с клавиатуры и настройку уменьшения анимации.
