# 🎮 Paimon Build Bot

AI-помощник по Genshin Impact, который собирает актуальные билды персонажей и отвечает на вопросы про механики игры.

## ✨ Возможности

- 🔥 **Актуальные билды** — парсит свежие гайды с определенного сайта через Jina Reader
- 🧠 **Анти-галлюцинации** — использует ReAct-архитектуру с разделением инструментов
- 💾 **Умный кэш** — сохраняет скачанные гайды для мгновенных повторных запросов

## 🏗️ Архитектура

Проект построен на базе **LangGraph** с ReAct-паттерном:

- **Агент** (`agent.py`) — принимает решения, какой инструмент использовать
- **Инструменты**:
    - `get_character_build` — получение билда (перевод имени персонажа → парсинг → структурирование)
    - `answer_general_question` — ответы на общие вопросы
- **Сервисы** (`services.py`) — утилиты для перевода, формирования URL, работы с кэшем
- **Telegram-бот** (`tg_bot.py`) — интерфейс для пользователей

## 🛠️ Стек технологий

### 🧠 Ядро
- **Python 3.11+** — основной язык
- **LangChain** — фреймворк для работы с LLM
- **LangGraph** — агентная архитектура (ReAct-паттерн)
- **OpenAI API** — LLM через прокси-провайдер (proxyapi.ru)

### 🤖 Telegram-бот
- **aiogram 3.x** — асинхронный фреймворк для Telegram Bot API
- **asyncio** — асинхронное выполнение запросов к LLM

### 🌐 Парсинг и данные
- **Jina Reader** (`r.jina.ai`) — конвертация веб-страниц в текст для LLM
- **requests** — HTTP-запросы к внешним API

### ⚙️ Конфигурация
- **pydantic-settings** — валидация и типизация настроек
- **python-dotenv** — загрузка переменных окружения из `.env`

### 🧪 Тестирование
- **pytest** — unit-тесты с мокированием внешних зависимостей
- **unittest.mock** — изоляция от LLM и Jina API

### 🚀 Инфраструктура
- **Git / GitHub** — контроль версий
- **venv** — виртуальное окружение Python
- **.gitignore** — защита секретов и мусора от попадания в репозиторий
